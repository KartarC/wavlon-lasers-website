Key Features

Built for Real-World Fabrication

IPG / Raycus Fiber Laser Source — Industry-leading fiber laser sources with 100,000+ hour MTBF and minimal maintenance requirements.
Raytools / Precitec Auto-Focus Cutting Head — Automatic focus adjustment maintains optimal focal point across changing material thickness.
Dual-Drive Gantry — Precision servo-driven gantry with linear guide rails delivers consistent ±0.03mm accuracy across the full bed.
Automated Exchange Table — Dual-platform pallet changer allows sheet loading during cutting — eliminating downtime between cuts.
Downdraft Extraction Table — Segmented downdraft table captures fumes and particles at the source, standard on all S-Series machines.
CypCut CAM Software — Full-featured nesting, cutting parameter optimization, and machine monitoring software — included and licensed.
Remote Diagnostics — VPN-based remote access allows our Canadian support team to diagnose and resolve issues without a site visit.
5-Year Machine Body Warranty — Structural components warranted for 5 years. Laser source warranty varies by manufacturer (IPG: 2yr, Raycus: 2yr).

Optional Add-Ons

Configure Your Machine

Every S-Series machine can be configured with optional accessories and upgrades at time of order.

🔄
Automatic Exchange Table
Dual-pallet system for continuous loading and unloading during cutting. Eliminates stop-start cycles between sheets.
🏗️
Tower Automation Integration
Connect to a Wavlon Tower Storage System for automated, lights-out production with up to 50 sheet capacity.
💨
High-Pressure Air Assist
High-pressure air cutting system reduces operating costs versus nitrogen — ideal for mild steel and aluminum.
🛡️
Full Class 1 Safety Enclosure
Laser-safe enclosure for compliance with Class 1 laser safety regulations. Required for some work environments.
💧
Upgraded Water Chiller
High-capacity industrial water chiller for demanding production environments and high duty-cycle operations.
📡
Factory MES Integration
ERP and MES connectivity via OPC-UA and REST API — for manufacturers tracking machine utilisation and production orders.
