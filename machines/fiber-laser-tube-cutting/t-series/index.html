    Features

    Designed for Tube & Profile Work

    Auto-Centering Chuck System — Pneumatic self-centering chuck accommodates round, square, rectangular, and custom profile tubes without manual adjustment.
    Front-Loading Conveyor — Automatic front-loading bundle feed system with roller conveyor for continuous production.
    6-Axis CNC Control — Simultaneous 6-axis control enables complex mitre cuts, saddle cuts, fish-mouth joints, and 3D bevel geometry.
    Anti-Scratch Roller Supports — Polyurethane roller supports along the full cutting length prevent surface scratching on polished or coated tube.
    Automatic Sorting & Offloading — Servo-driven cut-part sorting conveyor separates finished pieces automatically for downstream assembly.
    Remnant Length Detection — Automatic remnant detection minimises material waste from partial-bar cuts.
    CypTube CAM Software — Dedicated tube nesting and cutting software with DXF/STEP import, automatic joint generation, and NC output.
    5-Year Machine Warranty — Full structural warranty with Canadian spare parts support.
